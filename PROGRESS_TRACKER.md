## 💡 KEY LEARNINGS & INSIGHTS

### Week 1-2 Insights
- **Integer division trap:** `9/5 = 1` not `1.8` (use `9.0/5.0`)
- **Logical operators:** `&&` for ranges, `||` for alternatives
- **Enhanced for loop:** Cleaner than traditional for loop
- **ArrayList vs Array:** Dynamic vs fixed size

### Week 3 Insights
- **Constructor chaining:** Child must call `super()` first
- **Encapsulation:** Private fields + public getters/setters
- **Validation:** Always validate in setters
- **Method overriding:** Use `@Override` annotation
- **Code reuse:** Call `super.method()` to extend behavior

## 📝 NOTES FOR REVIEW

### Common Mistakes to Avoid
1. ❌ Using `||` instead of `&&` for range validation
2. ❌ Forgetting `super()` in child constructor
3. ❌ Not using `this` in constructors when parameter names match fields
4. ❌ Making setters return values (should be `void`)
5. ❌ Inconsistent bracing in if-else statements

### Best Practices Learned
1. ✅ Always validate input in setters
2. ✅ Use `@Override` when overriding methods
3. ✅ Call `super.method()` to reuse parent behavior
4. ✅ Make fields `private`, methods `public`
5. ✅ Write descriptive commit messages
6. ✅ Test edge cases (null, negative, empty)
